2 Latar Belakang Bisnis

2.1 Permasalahan Sebelumnya

MasalahDampak

2.2 Solusi SiLacak

  • Pelacakan real-time berbasis web (publik) dan API
  • Perhitungan ongkir otomatis dengan berat volumetrik & pembulatan ke atas
  • Pencarian resi cepat (< 200ms) dengan indeks dan eager loading
  • Keamanan berlapis: bcrypt, CSRF, XSS protection, parameter binding
  • Manajemen rahasia via .env dan .gitignore

11 Aturan Bisnis

11.1 Perhitungan Berat

LayananTarif/kgMin. KgKeterangan
RegulerRp 9.0001 kgStandar
ExpressRp 15.0001 kgPrioritas
KargoRp 6.00010 kgBarang besar
Same DayRp 25.0001 kgSampai hari ini

Rumus Berat Tagih:

berat_volumetrik = (P × L × T) / 6000
berat_tagih      = ceil(max(berat_aktual, berat_volumetrik))
berat_final      = max(berat_tagih, min_kg)

Contoh:

  • Berat aktual 1,3 kg → dibulatkan 2 kg (perbaikan bug floor)
  • Berat aktual 3 kg, dimensi 40×30×20 cm → volumetrik 4 kg → tagih 4 kg
  • Kargo 5 kg → tagih 10 kg (minimum)

11.2 Diskon & Asuransi

KondisiPerlakuan
Pelanggan memberDiskon 10% dari biaya dasar
Nilai barang > Rp 1.000.000Asuransi 0,2% dari nilai barang
Nilai barang ≤ Rp 1.000.000Tanpa asuransi

Rumus Total:

total = (berat_final × tarif) − diskon + asuransi

public function test_asuransi_aktif_jika_nilai_barang_diatas_1_juta()
{

17 Cara Instalasi

17.1 Prasyarat

  • PHP ≥ 8.2 dengan ekstensi: BCMath, Ctype, cURL, DOM, Fileinfo, JSON, Mbstring, OpenSSL, PCRE, PDO, Tokenizer, XML
  • Composer 2.x
  • MySQL 8.x atau MariaDB 10.3+
  • Node.js 20.x (opsional, untuk build Vite)

17.2 Langkah Instalasi

1. Clone Repository

git clone https://github.com/username/silacak.git
cd silacak

2. Install Dependency

composer install
npm install

3. Konfigurasi .env

cp .env.example .env
php artisan key:generate

Edit .env:

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=silacak
DB_USERNAME=root
DB_PASSWORD=

4. Buat Database

CREATE DATABASE silacak CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

5. Migrate & Seed

php artisan migrate:fresh --seed

6. Build Asset (Opsional)

npm run build

7. Jalankan Server

php artisan serve

Buka: http://localhost:8000

17.3 Perintah Sering Dipakai

# Reset database + seed ulang
php artisan migrate:fresh --seed

# Clear cache
php artisan cache:clear
php artisan config:clear
php artisan route:clear
php artisan view:clear

# Regenerate autoload
composer dump-autoload

# Lihat daftar route
php artisan route:list

# Cek koneksi database
php artisan db:show
